# 一、macOS 系统基础设置

---

## 1. 触控板设置

### 1.1 关闭“自然滚动”（个人习惯）
- **路径**：系统设置 → 触控板 → 滚动缩放  
- **操作**：勾选掉 **“自然滚动”**  
- **效果**：双指上下滚动逻辑调至与滚轮一致。

### 1.2 开启“辅助点按”（双指右键）
- **路径**：系统设置 → 触控板 → 点按与反馈  
- **操作**：勾选 **“双指点按”**
- **效果**：双指轻点触控板即可弹出右键菜单，与 Windows 习惯一致。

### 1.3 三指拖移（核心效率设置）
- **路径**：系统设置 → 辅助功能 → 指针控制 → 触控板选项  
- **操作**：
  1. 点击 **“触控板选项…”** 按钮。
  2. 勾选 **“使用触控板进行拖移”**。
  3. 在下拉菜单中选择 **“三指拖移”**。
- **效果**：
  - 拖动窗口或文件时，无需按住触控板，用三根手指轻放在触控板上移动即可。
  - 选中文本时，三指滑动可快速框选，非常高效。

## 2. 键盘设置

### 2.1 将 Caps Lock 映射为 Control 键（推荐）
Caps Lock 键很少使用，但 Control 键在终端、Vim、快捷键中频繁出现。将其映射为 Control 可减少左手小指移动距离。

- **路径**：系统设置 → 键盘 → 键盘快捷键 → 修饰键  
- **操作**：
  1. 在弹出窗口中，选择你的键盘（通常是“内建键盘”）。
  2. 将 **“Caps Lock 键”** 下拉菜单改为 **“Control”**。
- **可选映射**：如果你习惯用 Esc 退出 Vim 编辑模式，也可以将 Caps Lock 映射为 Escape，但 Control 在开发中用途更广（Ctrl+C 中断进程、Ctrl+A 行首等）。

### 2.2 功能键（Fn）行为设置
- **路径**：系统设置 → 键盘  
- **操作**：找到 **“按 Fn 键以”**，选择 **“显示快速操作”** 或 **“更改输入法”** 按个人喜好。  
- **附加**：勾选 **“将 F1、F2 等键用作标准功能键”**(在键盘快捷键中)，这样在按住 Fn 时才会触发媒体控制（如音量、亮度），否则 F1–F12 默认作为功能键使用（在 IDE 中调试时更顺手）。

## 3. Finder 设置

Finder 是 macOS 的文件管理器，合理设置可大幅提升文件操作效率。

### 3.1 显示隐藏文件
- **快捷键**：`Cmd + Shift + .`  
- **效果**：按一次显示隐藏文件（如 `.git`、`.env`），再按一次恢复隐藏。  
- **建议**：无需永久显示，用快捷键随时切换即可。

### 3.2 显示路径栏
- **操作**：打开任意 Finder 窗口，按 **`Cmd + Option + P`**  
- **效果**：窗口底部出现当前文件夹的路径，可直接拖拽路径中的文件夹到终端或应用。

### 3.3 显示状态栏
- **操作**：按 **`Cmd + Option + S`**  
- **效果**：窗口底部显示当前项目数量、可用空间等信息。

### 3.4 设置新 Finder 窗口默认打开位置
- **路径**：Finder → 屏幕左上角菜单栏 **“Finder”** → **“设置”** → **“通用”**  
- **操作**：在 **“开启新 Finder 窗口时显示”** 下拉菜单中选择 **“个人专属”**（即你的用户目录），或自定义一个文件夹如 `~/Developer`。

### 3.5 搜索范围设置
- **路径**：Finder → 设置 → “高级”  
- **操作**：将 **“执行搜索时”** 改为 **“搜索当前文件夹”**  
- **效果**：在 Finder 中按 `Cmd + F` 搜索时，默认只搜索当前打开的文件夹，而不是整个 Mac，更符合开发习惯。

## 4. Dock 与 Mission Control

### 4.1 自动隐藏 Dock
- **路径**：系统设置 → 桌面与 Dock  
- **操作**：开启 **“自动隐藏和显示 Dock”**  
- **效果**：Dock 栏在不使用时自动收起，给编辑器留出更多屏幕空间。

### 4.2 关闭“最近使用的应用程序”
- **路径**：系统设置 → 桌面与 Dock  
- **操作**：将 **“在 Dock 中显示最近使用的应用程序”** 取消勾选  
- **效果**：Dock 中只保留你固定放置的应用，减少干扰。

### 4.3 设置 Mission Control 快捷键
- **路径**：系统设置 → 键盘 → 键盘快捷键 → Mission Control  
- **建议**：保持默认 `Ctrl + ↑` 或 `F3`，但可增加 `Cmd + Tab` 的应用切换习惯，配合三指上划（触控板手势）快速查看所有窗口。

## 5. 系统隐私与安全

### 5.1 允许从“任何来源”安装应用（开发需要）
- 由于很多开发工具（如某些 Docker 插件、数据库客户端）可能来自未公证的开发者，你需要允许安装。  
- **操作**：打开终端，输入以下命令：
  ```bash
  sudo spctl --master-disable
  ```
- **说明**：这会在“系统设置 → 隐私与安全性”中启用“任何来源”选项。建议安装完所需软件后重新开启（`sudo spctl --master-enable`），但大部分开发工具都是安全的。

### 5.2 文件与文件夹访问权限
- 当你使用 VS Code 或终端操作某些目录时，系统可能会提示“xxx 想要访问桌面/下载文件夹”。点击“允许”即可，否则后续操作可能报错。


# 二、开发核心工具链配置

本部分提供在 **macOS (Apple Silicon)** 上配置全栈开发核心工具链的完整步骤，涵盖包管理、终端增强、版本管理、容器化及常用数据库工具。所有命令均在终端（Terminal.app 或第三方终端）中执行，请确保已安装 Xcode Command Line Tools（通常首次运行 `git` 或 `gcc` 时会自动提示安装，亦可手动执行 `xcode-select --install`）。

## 1. 包管理器 Homebrew

Homebrew 是 macOS 上最流行的包管理器，用于安装、升级和管理各类开发工具。

### 1.1 安装 Homebrew

在终端中执行以下命令：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

安装过程中可能会要求输入密码（用于 `/usr/local` 或 `/opt/homebrew` 的写入权限）。安装完成后，根据终端提示将 Homebrew 添加到 PATH（对于 Apple Silicon，通常需运行以下命令）：

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

### 1.2 验证安装

```bash
brew --version
```

应显示 Homebrew 版本号。

### 1.3 常用 Homebrew 命令

| 命令 | 说明 |
|------|------|
| `brew search <package>` | 搜索软件包 |
| `brew install <package>` | 安装软件包 |
| `brew upgrade <package>` | 升级软件包 |
| `brew list` | 列出已安装的包 |
| `brew cleanup` | 清理旧版本及缓存 |

## 2. 终端增强 (Oh My Zsh + 插件)

macOS 默认使用 Zsh（Z shell），通过 Oh My Zsh 可方便地管理主题和插件，提升命令行效率。
Oh My Zsh 是什么？**Oh My Zsh** 是一个开源的、社区驱动的 **Zsh 配置管理框架**，它的目标是让 Zsh变得强大、易用且美观，而无需你手动编写繁琐的配置文件。

### 2.1 安装 Oh My Zsh

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

安装完成后，默认配置文件为 `~/.zshrc`。

### 2.2 安装推荐插件

#### 2.2.1 zsh-autosuggestions（自动建议）

```bash
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
```

#### 2.2.2 zsh-syntax-highlighting（语法高亮）

```bash
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

### 2.3 配置插件

编辑 `~/.zshrc` 文件，找到 `plugins=(git)` 一行，替换为：

```bash
plugins=(git docker node npm zsh-autosuggestions zsh-syntax-highlighting)
```

保存后，重新加载配置：

```bash
source ~/.zshrc
```

### 2.4 可选：更换主题

Oh My Zsh 默认主题 `robbyrussell` 已足够简洁。若想更换，可在 `~/.zshrc` 中修改 `ZSH_THEME`，例如 `ZSH_THEME="agnoster"`（需额外安装 Powerline 字体）。

## 3. 版本管理工具(示例)

### 3.1 Node.js 版本管理：nvm

nvm 允许你在同一台机器上安装多个 Node.js 版本，并按项目切换。

#### 3.1.1 安装 nvm

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
```

安装脚本会自动将 nvm 的加载命令添加到 `~/.zshrc` 中。完成后，重新加载配置：

```bash
source ~/.zshrc
```

#### 3.1.2 验证 nvm

```bash
nvm --version
```

#### 3.1.3 安装 Node.js

```bash
nvm install 20   # 安装 Node.js 20 LTS
nvm alias default 20   # 设置默认版本
nvm use 20
```

#### 3.1.4 验证 Node.js 与 npm

```bash
node --version
npm --version
```

### 3.2 Python 版本管理：pyenv

pyenv 用于管理多个 Python 版本，避免与系统 Python 冲突。

#### 3.2.1 安装 pyenv

```bash
brew install pyenv
```

#### 3.2.2 配置 shell 环境

将以下内容添加到 `~/.zshrc` 文件末尾：

```bash
export PYENV_ROOT="$HOME/.pyenv"
export PATH="$PYENV_ROOT/bin:$PATH"
eval "$(pyenv init --path)"
eval "$(pyenv init -)"
```

重新加载配置：

```bash
source ~/.zshrc
```

#### 3.2.3 安装 Python

```bash
pyenv install 3.11.6   # 安装指定版本
pyenv global 3.11.6    # 设置全局默认版本
```

#### 3.2.4 验证

```bash
python --version
pip --version
```

#### 3.2.5 推荐：使用 poetry 管理项目依赖

```bash
curl -sSL https://install.python-poetry.org | python3 -
```

将 poetry 添加到 PATH（安装完成后会有提示），通常执行：

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## 4. Docker Desktop

Docker 是容器化核心工具，全栈开发中用于搭建数据库、中间件等环境。

### 4.1 下载与安装

访问 [Docker Desktop for Mac (Apple Silicon)](https://docs.docker.com/desktop/install/mac/#install-and-run-docker-desktop-on-mac)，下载 `.dmg` 文件并安装。或通过 Homebrew 安装：

```bash
brew install --cask docker
```

### 4.2 启动与配置

1. 启动 Docker Desktop（在应用程序中找到并打开）。
2. 首次运行会要求授权，输入密码后 Docker 将在后台运行（安装并启用 Rosetta）。
3. 在菜单栏 Docker 图标处点击 → **Settings** 进行配置：

   - **Resources → Advanced**：  
     - 内存（Memory）推荐设置为 **8 GB**（48GB 内存的机器可分配 12GB）。  
     - Swap 设置为 **4 GB**。  
     - CPU 数量保持默认即可。
   - **General**：勾选 **“Start Docker Desktop when you log in”** 方便自动启动。
   - **Docker Engine**：无需修改默认配置，保持 `"experimental": false` 即可。

### 4.3 验证安装

在终端中运行：

```bash
docker --version
docker run hello-world
```

如果看到欢迎信息，说明 Docker 工作正常。

### 5.3 Git及其他常用工具

```bash
brew install wget curl tree htop   # 基础工具
brew install git                   # Git（系统已自带，但可更新至最新）
```
- **`wget`**  
    强大的网络下载工具，支持 HTTP、HTTPS、FTP 等协议。可以断点续传、递归下载整个网站，适合从终端直接下载文件。
    
- **`curl`**  
    更灵活的网络传输工具，支持更多协议（如 SFTP、SCP、SMTP 等）。常用于 API 测试、发送 HTTP 请求、上传/下载数据。macOS 已预装，但 Homebrew 版本更新更快。
    
- **`tree`**  
    以树形结构递归显示目录内容，能直观地展示文件夹层级和文件列表。例如 `tree` 会输出类似下图的效果：
    
    text
    
    project/
    ├── src/
    │   ├── main.c
    │   └── utils.h
    └── README.md
    
- **`htop`**  
    交互式进程查看器，比系统自带的 `top` 更友好。支持鼠标操作、彩色显示、垂直/水平滚动，可以方便地搜索进程、直接杀掉进程、监控 CPU/内存占用。

### 5.4 数据库图形化管理工具（可选）

- **TablePlus**：通过官网或 App Store 下载，免费版功能足够。
- **Beekeeper Studio**：开源免费，支持多种数据库。

## 6. 验证整体环境

创建几个简单的测试项目，验证各工具是否协同工作。

### 6.1 Node.js + Docker

#### (1) 在终端里创建一个 Node.js 项目环境，并安装 Express 框架:

- 在主目录（`~`）下的 `Document` 文件夹中，创建一个名为 `test-env` 的新目录并切换过去。
- 使用nvm切换node版本为20.x
- **`npm init`**：初始化一个新的 Node.js 项目，会创建一个 `package.json` 文件，用于管理项目的依赖、脚本等信息。
- **`-y`**：跳过所有交互式提问，使用默认值快速生成 `package.json`。
- **结果**：在项目根目录生成一个基本的 `package.json` 文件。
- **`npm install`**：安装 Node.js 包（依赖）。
- **`express`**：安装流行的 Node.js Web 框架 Express。
- **效果**：
    - 将 Express 下载到 `node_modules` 文件夹。
    - 在 `package.json` 中添加 `express` 作为项目依赖。 
    - 生成 `package-lock.json` 文件，锁定依赖版本。

```bash
mkdir ~/Documents/test-env && cd ~/Documents/test-env
nvm use 20
npm init -y
npm install express
```

#### (2) 在`test-env`下创建一个 `index.js` 文件：

- 引入 `express` 模块，返回一个函数，赋值给 `express` 变量。
- 调用 `express()` 创建一个 Express 应用实例，通常命名为 `app`。这个实例包含了路由、中间件等核心功能。
- 定义服务器监听的端口号，这里使用 `3000`，是开发时常用的端口。
- 定义一个 **路由处理函数**：当用户通过 `GET` 方法访问根路径 `/` 时，执行回调。
- `req` 对象代表请求，`res` 对象代表响应。
- `res.send()` 方法向客户端发送一段文本（或 HTML、JSON 等），并自动结束响应。
- 启动 HTTP 服务器，监听在 `port` 指定的端口。
- 第二个参数是一个回调函数，在服务器启动成功后执行，打印一行提示信息，告诉用户服务的访问地址。

```javascript
const express = require('express');
const app = express();
const port = 3000;

app.get('/', (req, res) => {
  res.send('Hello World from Node.js!');
});

app.listen(port, () => {
  console.log(`App listening at http://localhost:${port}`);
});
```

#### (3) 运行：

```bash
node index.js
```

#### (4) 访问 `http://localhost:3000` 应看到响应。
```
Hello World from Node.js!
```

## 附录：常见问题

| 问题 | 解决方案 |
|------|----------|
| `brew install` 报错 `Permission denied` | 确保已正确设置 Homebrew 的 PATH，或执行 `sudo chown -R $(whoami) /opt/homebrew`（仅限个人机器） |
| `nvm` 命令找不到 | 检查 `~/.zshrc` 中是否包含 nvm 的加载脚本，并执行 `source ~/.zshrc` |
| `pyenv` 安装的 Python 无法使用 pip | 运行 `pyenv rehash`，确保 `pip` 路径正确 |
| Docker 启动缓慢或内存不足 | 调整 Docker Desktop 的资源分配（见 4.2 节） |
| 终端字体显示异常 | 安装 Powerline 字体，如 `brew install --cask font-meslo-lg-nerd-font`，并在终端设置中选用该字体 |
